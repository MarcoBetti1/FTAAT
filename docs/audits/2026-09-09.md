# FTAAT audit — 2026-09-09

Baseline: `0e02638` from MarcoBetti1/FTAAT. Fresh clone, no existing local changes.

| Finding | Consequence | Resolution |
|---|---|---|
| Batch outputs zipped with requests by line order | Correct responses could be graded against the wrong key | Retired unsafe batch orchestration; new serial calls tied to hashed case/model IDs |
| Minimum response/expected lengths used as denominator | Missing answers could inflate accuracy | Full expected denominators plus exact trial endpoint |
| Empty response indexed at first/last character | Crash on empty completions | Total grading for empty strings |
| Duplicate flag overwritten | Invalid detection | Exact response and independent format/content metrics |
| n*k output cap ignores separators/newlines | Artificial truncation | Explicit per-model output cap and expected-byte precheck; incomplete outcomes separated |
| Single-token inventory claimed joined fixed length | Unjustified token consistency claims | K renamed symbols; official per-model full-request count and actual usage |
| Model name captured before .env loading | Configuration can be ignored | Explicit per-run model profiles |
| Timestamp-only trial filenames | Fast trials could overwrite each other | Durable append-only ledger and SHA-256 IDs |
| Resume based only on N/K filenames | Different prompts/trials could be silently skipped | Manifest identity includes configuration, generated cases and runner source hash |
| No spend guard / retry accounting | Unbounded or uncertain cost | Durable pre-dispatch reservations, no automatic retry, cumulative per-run budget |
| Windows-only pywin32 in default requirements | macOS installation failure | Lean package with optional legacy environment |
| Root test.py moves files on import | Test discovery can mutate results | Main guard; tests isolated under tests/ |
| Tracked Python bytecode | Generated files in source control | Removed tracked caches |
| Prompt template loaded relative to working directory | Notebook import fragile | Resolve relative to module |
| Unordered set becomes random vocabulary | Seed not sufficient | Sorted legacy inventory; new local PRNG |

New runtime integrations: OpenAI Responses API and Anthropic Messages API. No batch
submission or arbitrary custom endpoint. New offline tests cover independent ground
truth solvers, accounting, missing output, model payloads, resume, input/output limits,
and uncertain billing. A one-case live smoke test passed for GPT-4o Mini, GPT-4.1 Mini, GPT-5.6 Luna and Claude Haiku 4.5. Preflight input counts equaled returned input usage on all four requests. This validates the initial API path, not model reliability.

The original repository does not include the previously described Streamlit dashboard
or frontier walker source. The gitignore explicitly excludes some of those paths.
The notebooks and stored token inventories are present. We do not assume missing
features were recovered or tested.

Scope: first reliable OpenAI/Anthropic workflow. Historical DeepSeek/Ollama code and
notebooks remain available but unverified; old API execution is not used for this video.
